# JS-Form-Validation-Project

A browser-based form validation project built with HTML, CSS, and JavaScript along other devDependencies

## About

This project practices form validation using JavaScript and the Constraint Validation API. The form collects:

Email
Country
Postal Code
Password
Password Confirmation

The form uses live inline validation, so users receive feedback while filling it out.

## Features

Validates fields as the user types

Validates fields when the user leaves them

Displays custom error messages

Highlights invalid fields

Checks that passwords match

Prevents submission when there are validation errors

Displays a high five when the form is successfully submitted

Uses novalidate to handle validation through JavaScript

Uses CSS :user-valid and :user-invalid pseudo-classes

## Tech Stacks

HTML5 | CSS3 | JavaScript | Constraint Validation API
